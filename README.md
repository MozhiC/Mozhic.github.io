# Organic Graph Personal Site — V4

## New intro experience

The page now opens with only:

**Enter Mozhi's Power Grid**

When clicked:

1. The intro fades away.
2. The graph canvas fades/zooms in.
3. Edges draw outward progressively.
4. Nodes appear one-by-one with different sizes.
5. The force-directed motion starts immediately.
6. The graph then behaves like V3: organic motion, unequal spacing, unequal node sizes, focus/fade interactions.
